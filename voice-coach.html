关于你的 API Key:本页采用 BYOK(自带 Key)。Key 只保存在你当前浏览器的 localStorage,仅在你发起对话时通过 HTTPS 发给你自己部署的中转函数,再转发给千问。Key 不会写进网页源码、不会上传到 GitHub 仓库、不会发给第三方。请勿在公用电脑上保存 Key;用完可点"清除 Key"。

1 · 连接设置

千问 API Key(你自己的,存本地)
中转接口地址(Proxy URL)
模型

Key 未设置 · 语音识别 检测中

2 · 陪练设置

你现在的阶段(影响追问难度)
话题(可留空,让陪练自选)
陪练规则(系统提示,可展开查看)

口语本质是"说"。本工具用浏览器语音识别把你的话转成文字再发给千问,它看不到真实发音,不会、也不应据此给雅思口语分。发音和最终评分请找熟悉雅思标准的老师。

3 · 对话

设置好 Key 和中转地址后,点"开始新一轮陪练"。
部署与计费说明

· 本页 + 中转函数部署在你自己的 Vercel(连同你的 GitHub 仓库)。详见仓库里的 README.md。
· 中转函数只转发请求,不保存你的 Key;Key 每次由浏览器随请求发送。
· 调用千问会按阿里云百炼的实际用量计费,额度和价格以你的百炼控制台为准。建议在控制台设用量上限。
· 语音识别/朗读用浏览器自带的 Web Speech API,在 Chrome / Edge 支持最好;Safari、Firefox 可能不支持识别,此时请直接打字。
· 识别需要 HTTPS;Vercel 和 GitHub Pages 均为 HTTPS,本地直接打开 file:// 可能无法录音。
